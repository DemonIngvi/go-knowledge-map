# Исходники «Карты знаний Go-бэкенда»

- `go-knowledge.html` — каркас страницы: стили, граф, план, повторение, тесты.
- `data/*.js` — статьи (169 тем): `KB.add({id, t, b, s, l, a, x, m})`.
- `quiz/q1–q6.js` — тесты: `KB.q(id, [[вопрос, верный, неверный×3, пояснение], …])`.
- `viz.js` — отрисовщики схем, графиков и кода; `viz-data.js` — визуализации по темам.
- `check.js` — проверка статей и ссылок: `node check.js .`
- `build.js` — сборка одного файла: `node build.js . ../index.html`
