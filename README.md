# Карта знаний Go-бэкенда

Интерактивная карта знаний для Go-разработчика: что изучать, в каком порядке и как не забыть изученное.

- **Граф знаний.** 169 тем в 15 блоках: язык Go, инструменты, тесты, архитектура, PostgreSQL, Kafka, сеть, балансировка, Kubernetes, Linux, наблюдаемость и другие. Связи между темами — это перекрёстные ссылки статей.
- **План обучения.** 10 этапов со сроками и целями. Каждая тема помечена: ядро (спрашивают на собеседованиях), важно в работе или кругозор.
- **Статьи.** На каждую тему есть статья с ключевыми моментами, перекрёстными ссылками и источниками для углублённого чтения. В 165 темах есть схемы (блок-схемы, диаграммы последовательности, временные шкалы, графики) и примеры кода на Go. Схемы можно переключить в стиль карандашного рисунка.
- **Тесты и интервальное повторение.** По 3 вопроса на тему, всего 507. Сданный тест запускает таймер: 3 → 7 → 14 → 30 → 60 → 120 → 240 дней. Когда срок выходит, тема устаревает, и страница предлагает пройти повторение — тесты по устаревшим темам подряд.
- **Карта памяти.** Отдельный режим графа раскрашивает темы и блоки по свежести знаний: синие оттенки — свежо, коралловый — срок подходит, тёмно-красный — истёк.

Основа карты — видео [«Какой стек нужно знать Golang-разработчику?»](https://www.youtube.com/watch?v=vSWJD6GxkOA) канала Golang School, расширенное до полноценной программы.

## Как запустить

### Windows: прогресс в файле (рекомендуется)

1. Скачайте архив `go-knowledge-map-windows.zip` из [Releases](../../releases) и распакуйте его в любую папку.
2. Запустите `gokb-server.exe`. Откроется браузер со страницей `http://127.0.0.1:8090/`.
3. Прогресс сохраняется в `progress.json` рядом с программой. Повторный запуск при работающем сервере просто откроет страницу.

Остановить сервер: закрыть окно консоли или нажать Ctrl+C.

### Любая ОС: из исходников

```sh
git clone https://github.com/DemonIngvi/go-knowledge-map.git
cd go-knowledge-map/server
go run . -root ..
```

Нужен Go 1.22 или новее. Сервер слушает только `127.0.0.1` и отклоняет запросы с чужих доменов.

### Без сервера

Откройте `index.html` в браузере. Всё работает, но прогресс хранится только в этом браузере. Перенести его можно кнопками «Экспорт» и «Импорт» на вкладке «Повторение».

## Как устроено

```
index.html          собранная страница: один файл без внешних зависимостей, кроме шрифтов
src/
  go-knowledge.html каркас: стили, граф, план, повторение, тесты
  data/*.js         статьи: KB.add({id, t, b, s, l, a, x, m})
  quiz/*.js         тесты: KB.q(id, [[вопрос, верный ответ, неверный ×3, пояснение], …])
  viz.js            отрисовщики схем, графиков и кода (SVG)
  viz*.js           визуализации к статьям
  check.js          проверка статей, перекрёстных ссылок и терминов
  build.js          сборка index.html
server/main.go      локальный сервер: отдаёт страницу, GET/PUT /api/progress → progress.json
```

После правок пересоберите страницу:

```sh
cd src
node check.js .
node build.js . ../index.html
```

Формат статей: абзацы разделяются пустой строкой, `## ` — подзаголовок, `- ` — пункт списка, `**жирный**`, `{{код}}`, `[[id-темы]]` или `[[id-темы|текст]]` — перекрёстная ссылка.
