# Карта знаний Go-бэкенда

Интерактивная карта знаний для Go-разработчика: что изучать, в каком порядке и как не забыть изученное.

- **Граф знаний.** 169 тем в 15 блоках и 5 зонах: «Код и качество», «Распределённые системы», «Данные», «Сеть», «Платформа». Зоны посчитаны по плотности перекрёстных ссылок между статьями. Ленты показывают, сколько связей между блоками; есть матрица связности. Кнопки подсвечивают выбранные зоны и блоки, при наведении на тему появляется карточка с её связями.
- **Дерево знаний.** Темы разложены по слоям глубины (этапам плана). Щелчок по теме подсвечивает маршрут от начальных тем до неё, показывает, что она открывает дальше, или путь между двумя темами.
- **План обучения.** 10 этапов со сроками и целями. Каждая тема помечена: ядро (спрашивают на собеседованиях), важно в работе или кругозор.
- **Статьи.** Ключевые моменты, перекрёстные ссылки, источники для углублённого чтения. В 165 темах есть схемы — блок-схемы, диаграммы последовательности, временные шкалы, графики — и примеры кода на Go. По умолчанию схемы нарисованы в стиле карандашного эскиза.
- **Тесты и интервальное повторение.** По 3 вопроса на тему, всего 507. Сданный тест запускает таймер: 3 → 7 → 14 → 30 → 60 → 120 → 240 дней. Когда срок выходит, страница предлагает повторение — тесты по устаревшим темам подряд.
- **Карта памяти.** Режим графа раскрашивает темы, блоки и зоны по свежести знаний.

Основа карты — видео [«Какой стек нужно знать Golang-разработчику?»](https://www.youtube.com/watch?v=vSWJD6GxkOA) канала Golang School, расширенное до полноценной программы.

## Как запустить

### Windows: прогресс в файле (рекомендуется)

1. Скачайте `go-knowledge-map-windows.zip` из [Releases](../../releases) и распакуйте в любую папку.
2. Запустите `gokb-server.exe`. Откроется `http://127.0.0.1:8090/`.
3. Прогресс сохраняется в `progress.json` рядом с программой. Повторный запуск при работающем сервере просто откроет страницу.

### Из исходников

```sh
git clone https://github.com/DemonIngvi/go-knowledge-map.git
cd go-knowledge-map/server
go run . -web ../web -data ../progress.json
```

Нужен Go 1.22 или новее. Сервер слушает только `127.0.0.1`, отдаёт папку `web/` без листинга каталогов и отклоняет запросы с чужих доменов.

### Без сервера

Откройте `web/index.html` в браузере или соберите один файл: `node scripts/build.js` → `dist/index.html`. Прогресс тогда хранится только в браузере; перенести его можно кнопками «Экспорт» и «Импорт» на вкладке «Повторение».

## Структура

```
web/                         страница: открывается в браузере и отдаётся сервером
  index.html                 разметка и подключение стилей
  css/                       tokens · layout · graph · tree · plan · article · review · viz · sketch
  js/loader.js               загружает темы из манифеста, затем модули приложения
  js/core/                   kb (реестр) · config (блоки, этапы, зоны) · markup · topics · progress
  js/views/                  graph · graph-zoom · tree · nav · plan · terms · topic · session · review
  js/features/               quiz · reminder · memmap · sketch
  js/viz/engine.js           отрисовка схем, графиков и кода
  content/manifest.js        список тем по блокам
  content/<блок>/<тема>.js   одна тема — один файл: статья, тест и схемы
server/main.go               локальный сервер: web/ + GET/PUT /api/progress → progress.json
scripts/check.js             проверка контента: id, ссылки, разметка, тесты, схемы
scripts/build.js             сборка одного файла dist/index.html
```

## Как добавить или изменить тему

1. Создайте или отредактируйте `web/content/<блок>/<id>.js`:
   - `KB.add({id, t, b, s, l, a, x, m})` — статья: id, заголовок, блок, этап, уровень (1 ядро, 2 важно, 3 кругозор), синонимы, текст, ссылки «читать подробнее»;
   - `KB.q(id, [[вопрос, верный ответ, неверный, неверный, неверный, пояснение], …])` — тест;
   - `KB.v(id, [{type: 'flow' | 'seq' | 'chart' | 'gantt' | 'code', after: 'Заголовок раздела', …}])` — схемы.
2. Новую тему добавьте в `web/content/manifest.js`.
3. Проверьте: `node scripts/check.js`.

Разметка текста статьи: абзацы через пустую строку, `## ` — подзаголовок, `- ` — пункт списка, `**жирный**`, `{{код}}`, `[[id-темы]]` или `[[id-темы|текст]]` — перекрёстная ссылка, строки `| … |` — таблица.
