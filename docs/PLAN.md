## 3. Дерево: меньше дублирующих связей между блоками

Готово (2026-11-06), флажок «одна связь между рамками» включён по умолчанию и действует **только на отрисовку в режимах «Все предпосылки темы» и «Несколько тем»**. Рамка — зона на уровне. Между парой рамок рисуется одна связь (главная → не транзитивная → ближайшие уровни); к рамке, уже достижимой через другие подсвеченные рамки, линия не рисуется; внутри рамки — все. Сами предпосылки, маршрут и список тем не меняются. Фон и «Маршрут к теме» не затронуты. Замер: pg-multixact 365 → 102 линий.


Идея владельца: в режимах **«Все предпосылки темы»** и **«Несколько тем»** не рисовать все связи между парой блоков, если связь между ними уже показана — достаточно одной.

Варианты для обдумывания:
- для каждой пары «блок предпосылки → блок темы» в выбранном наборе оставлять одну, самую «короткую» связь (ближайшие уровни), остальные скрывать;
- либо заменить пачку связей между блоками одной толстой лентой с числом связей, как на графе;
- не трогать связи внутри одного блока — они показывают порядок изучения.

Решение принять после прототипа на одной-двух темах 4–5 уровня.

## 5. Интерфейс: дерево первым, граф с картой памяти, размеры

Готово (2026-11-06): дерево — первая вкладка и стартовый экран; карта памяти включена по умолчанию (выключение запоминается); граф по высоте окна, фильтры в колонке справа, описание свёрнуто; на графе связи не рисуются совсем (ни между темами, ни ленты между блоками), нет реакции на наведение; блоки шире, зоны ближе, подписи тем не перекрываются (раскладка учитывает длину подписи) — только кнопки, фильтры, масштаб и щелчки. Вертикальное дерево: кнопка «Вертикально» во вкладке «Дерево» (уровни — строки сверху вниз, зоны — постоянные столбцы, в ячейке до 10 тем в столбце); выбор запоминается, по умолчанию горизонтальное. **Ждёт решения владельца**: какой вид по умолчанию.


- **Дерево — первая вкладка** и стартовый экран вместо графа: оно отвечает на главный вопрос «что учить дальше». Граф — второй вкладкой, как обзор связности.
- **Граф открывается с включённой картой памяти** (подсветка по устареванию тем) по умолчанию; выключение запоминается.
- **Граф должен помещаться в окно.** Сейчас он часто не влезает. Варианты:
  - вписывать по реальному размеру области при каждом показе и изменении окна (сейчас масштаб считается один раз);
  - компактнее раскладка: зоны ближе, радиусы блоков меньше, подписи зон внутри облаков;
  - высота области графа по окну (`100dvh` минус шапка и панель фильтров), фильтры свернуть в одну строку или выпадающую панель;
  - кнопка «во весь экран».
- **Вертикальное дерево**: уровни сверху вниз, зоны — колонками слева направо. Плюсы: естественное чтение «сверху — фундамент, снизу — экспертиза», зоны становятся постоянными колонками (как в плане). Минусы: в уровне 3 больше 50 тем — понадобится перенос внутри зоны. Сделать прототип отдельной страницей (как с графом зон) и сравнить с горизонтальным, затем выбрать или оставить переключатель.

## 10. Критическая вычитка содержания (запрос владельца, 2026-11-06)

Прочитать каждую тему как человек, который её изучает, и исправить:
- **Статья**: понятна ли без внешних источников; дополнить недостающим (определения, «зачем», как устроено, типичные ошибки). Без воды и без повторов одного и того же.
- **Тест**: вопросы проверяют понимание из статьи, а не узнавание слов; правдоподобные неверные варианты; есть вопросы на применение и на подвох.
- **Примеры**: реалистичные, рабочий код и команды, а не иллюстрации «из головы».
- **Сложный случай**: реальный разбор со ссылкой на первоисточник там, где он есть; иначе подробный обобщённый случай с механизмом сбоя, диагностикой и исправлением, а не 3 строки.

Метод: два агента на тему — первый правит, второй независимо проверяет правку по тем же критериям (факты, понятность, вода, тест проверяет тему); спорное — третий проход. Сначала пробная пачка с замером, затем по этапам. После каждой пачки: check.js, коммит, обновление обоих репозиториев.
