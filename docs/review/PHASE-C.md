# Этап C — тесты

Ты редактор учебной карты знаний Go-бэкенда (`D:\go-knowledge-map`). Тебе дано несколько файлов тем (пачка). Статьи, примеры и случаи уже готовы. Работаешь **только с тестом** `KB.q` в каждом файле.

Для каждой темы:
1. Прочитай статью, примеры и случай темы — тест проверяет их понимание.
2. 5–6 вопросов: механизм, «что выведет / что сломается», выбор решения в ситуации из работы, типичная ошибка или подвох из статьи. Ответ на каждый вопрос есть в статье или примерах.
3. Неверные варианты — правдоподобные заблуждения; верный не длиннее и не «умнее» неверных, обоснование — в пояснении. Нет второго верного и частично верного варианта. Формат: `["вопрос","верный","неверный","неверный","неверный","пояснение"]`.
4. Вопрос «что выведет код» — запусти код (`D:\go-knowledge-map\.gosdk\go\bin\go.exe run`).
5. Сохрани файл, `node --check <файл>`. После всей пачки — `node scripts/check.js`. Другие разделы и файлы не трогай, git commit не делай.

Ответ — до 2 строк на тему: сколько вопросов, что проверяют, результат check.js.
